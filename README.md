# Pyare Bache 🎮🧸

**Pyare Bache** is a fun and interactive PWA (Progressive Web App) game specially designed for kids and casual gamers. Players control a character at the bottom of the screen and try to **catch falling stars** while avoiding misses. Each star caught increases the score, and the game becomes progressively more challenging as the player’s score rises. High scores are saved automatically in the browser.

## Key Features
- Touch Controls: Mobile swipe & tap, desktop mouse
- High Score Tracking: Saved in browser
- Progressive Difficulty: Speed increases with score
- Installable PWA: Full-screen app experience
- Kid-Friendly Theme: Soft colors & simple design

## How to Play
1. Open the game in a browser
2. Move character left/right by touch or mouse
3. Catch falling stars for points
4. Avoid misses or game ends
5. Beat your high score

## Installation
1. Open the game link in browser
2. Tap menu → Add to Home Screen / Install
3. Enjoy full-screen app experience
